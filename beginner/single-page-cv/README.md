# Single Page CV

Página de currículo desenvolvida com HTML e CSS como parte do desafio do roadmap.sh.

## Conteúdo

- Informações pessoais e contato
- Habilidades
- Formação acadêmica
- Experiência profissional
- Links para perfis online

## Tecnologias

- HTML5
- CSS3

## Como executar

1. Clone o repositório:

   ```bash
   git clone <URL_DO_REPOSITORIO>
   ```

2. Entre na pasta do projeto:

   ```bash
   cd single-page-cv
   ```

3. Abra o arquivo `index.html` no navegador.

## Desafio

Este projeto segue o desafio [Single Page CV](https://roadmap.sh/projects/single-page-cv), do roadmap.sh.
